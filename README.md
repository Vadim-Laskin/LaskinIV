# Когда я на связи — сайт-расписание + Telegram-бот

Тёмная страница доступности: показывает персональное расписание по `?tg_id=`,
иначе — общее расписание по календарю. Управляется через `/panel`.
Разворачивается на Netlify (статика + Netlify Functions + Netlify Blobs,
без сторонних БД).

## Структура

```
public/            — публичный сайт (index.html) и панель (admin/)
netlify/functions/ — серверная логика (Node.js, Netlify Functions)
```

## 1. Переменные окружения (Netlify → Site settings → Environment variables)

| Переменная              | Назначение                                              |
|--------------------------|----------------------------------------------------------|
| `ADMIN_PASSWORD`         | Пароль для входа в `/panel`                              |
| `ADMIN_SECRET`           | Случайная длинная строка — подписывает сессию админа     |
| `TELEGRAM_BOT_TOKEN`     | Токен бота от @BotFather                                 |
| `TELEGRAM_WEBHOOK_SECRET`| (необязательно) секрет для проверки вебхука Telegram      |
| `SITE_URL`               | Адрес сайта (например `https://my-site.netlify.app`) — нужен, чтобы кнопка «Отписаться» в сообщении бота вела обратно на сайт |

Netlify Blobs включён автоматически для деплоев на Netlify — отдельно
подключать ничего не нужно.

## 2. Деплой

1. Загрузите эту папку в Git-репозиторий (GitHub/GitLab) или перетащите
   как есть на app.netlify.com → "Add new site" → "Deploy manually".
2. При Git-деплое Netlify сам подхватит `netlify.toml`
   (`publish = public`, `functions = netlify/functions`).
3. Добавьте переменные окружения из таблицы выше и передеплойте сайт.

## 3. Подключение Telegram-бота

1. Получите токен у @BotFather (у вас он уже есть) и узбер username бота.
2. Пропишите вебхук (один раз, из терминала/Postman):

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<ваш-сайт>.netlify.app/api/telegram-webhook&secret_token=<TELEGRAM_WEBHOOK_SECRET>
```

3. В `/panel` → «Расписание и настройки» укажите username бота — на сайте
   появится кнопка «Подписаться в Telegram».
4. Когда пользователь пишет боту `/start`, бот сохраняет его chat_id и
   присылает подтверждение. `/stop` — отписка.
5. Кнопка «Разослать „Я свободен“» в панели шлёт сообщение всем
   подписчикам. Если Telegram сообщает, что доставить сообщение
   невозможно (бот заблокирован, чат удалён и т.п.) — такой подписчик
   автоматически удаляется из списка рассылки.

## 4. Как работает подписка через `tg_id`

Когда ссылка на сайт открыта с `?tg_id=123456789` и у вас указан username
бота в панели, под расписанием появляется кнопка «Подписаться на
уведомления»:

1. Сайт спрашивает сервер: писал ли этот `tg_id` боту хоть что-нибудь
   раньше (сервер запоминает это при любом сообщении в вебхуке).
2. Если писал — человек подписывается сразу, без открытия Telegram, и
   бот присылает ему подтверждение с кнопкой «Отписаться», которая ведёт
   обратно на сайт (`?tg_id=...&unsub=1`) и отписывает автоматически при
   открытии.
3. Если ещё не писал — сайт покажет просьбу сначала открыть бота и
   написать что угодно, и кнопку «проверить снова».

## 5. Персональное расписание по Telegram ID

Ссылка вида `https://<ваш-сайт>.netlify.app/?tg_id=123456789` покажет
персональное сообщение/расписание, если оно добавлено в панели
(«Персональные окна»). Если записи нет — посетитель увидит общее
расписание, собранное из недельного шаблона и (опционально) календаря.

## 6. Синхронизация с календарём

В Google Calendar: Настройки календаря → "Секретный адрес в формате
iCal" → скопируйте ссылку `.../private-xxxx/basic.ics` и вставьте в поле
«Ссылка на приватный ICS-адрес» в панели. Это не требует OAuth и работает
сразу. События из календаря вычитаются из недельного шаблона как «занято».

Ограничение: разбор ICS в этом проекте — облегчённый (без внешних
библиотек), он корректно обрабатывает одиночные события и простые
еженедельные/ежедневные повторения. Очень сложные правила повторения
могут раскрыться не идеально.

## 7. Локальная разработка

```
npm install
npx netlify dev
```

`netlify dev` поднимет и статику, и функции, и локальную эмуляцию Blobs.
